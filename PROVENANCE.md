# Source provenance

This standalone solver repository was prepared from the working-tree release
candidate of the RMI-dispersion-relation research project. It starts its own
Git history; it is not a clone of the full research repository.

The imported artifact was `rmi-solver-candidate-20260923.zip`, SHA-256:

```text
4ae078f7b5d1022254dd6c1cede5a68e1f9459b054ec0c14fca1dbd63d6b3f73
```

`release/UPSTREAM_SOURCE_MANIFEST.json` records the imported file hashes and
base commit. Its hashes apply to the original imported snapshot, not to
subsequent publication documentation edits in this repository. Each newly
built archive has its own SOURCE_MANIFEST.json with current file hashes.

Preparation added repository setup files, CI, citation/release templates,
and a reference example, and revised the documentation for standalone use.
The numerical solver and canonical coefficient formulas were copied intact
from the tested candidate.
