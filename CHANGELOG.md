# Changelog

## 0.1.0rc1 — local candidate

- Solver-focused source distribution with canonical symbolic coefficients and
  derivation files.
- Float64 verification workflow with targeted high-precision refinement.
- Reusable full arbitrary-precision reference solver and JSON command.
- 118 numerical and workflow tests, including precision-convergence and
  medium-exchange checks.
- Recorded dependencies, source checksums, a reference example, and a GitHub
  Actions test workflow.

This is a local release candidate. The initial public tag and release date
will be recorded after authorship, licensing, and repository metadata are set.
